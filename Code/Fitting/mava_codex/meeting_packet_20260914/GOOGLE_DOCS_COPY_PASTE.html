Mavacamten Sequential Analysis

PI meeting — September 14, 2026
Authoritative run: mava_seq_20260908_v2 · 60 completed fits

Main result: Acute mavacamten reduces peak force to approximately one-third of baseline in both Control and H251N. This suppression cannot be reproduced by changing only SRX/DRX exchange and attachment rates. Allowing the forward power-stroke parameter k_5_0 to decrease produces the dominant fit improvement, although exact parameter magnitudes remain practically non-identifiable.

5. Identifiability

  • All 60 fits completed and converged numerically.
  • Every parameter in each selected final-stage ensemble is classified as practically non-identifiable.
  • Each group has only one near-optimal start.
  • Shared Control reaches the k_3 = 10× boundary.
  • H251N reaches the k_4_0 = 10× boundary.
  • Independent Control reaches k_2 = 10× and k_4_0 = 0.1×.
  • The adaptive diagnostic requests additional final-stage restarts for all groups.

6. Questions for the PI

  1. Do all six force traces share the same electrical or calcium-stimulus clock, or can each exported trace have an arbitrary time offset?
  2. Should the apparent 145 ms acute Control delay be preserved as biology or corrected with independent onset alignment?
  3. Is “mavacamten requires reduced power-stroke capacity, while exact rates remain non-identifiable” sufficiently defensible for the BPS abstract?
  4. Should the next analysis restore the required k_2 = 10 × k_1 constraint?
  5. Should the 24-hour recovery traces be modeled next or remain descriptive validation data?

Recommended presentation statement

Acute mavacamten reduced peak force to 34.7% of baseline in Control and 33.1% in H251N. Models permitting changes only in SRX/DRX exchange and attachment kinetics failed to reproduce the acute waveforms. Allowing the forward power-stroke parameter k_5_0 to decrease produced the dominant AIC improvement in every analysis. Exact kinetic fold changes remain practically non-identifiable, and the Control result depends on unresolved stimulus-time alignment.
